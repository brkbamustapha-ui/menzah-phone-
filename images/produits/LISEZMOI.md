# Photos des produits

Déposez ici les photos de vos produits (formats `.jpg`, `.png` ou `.webp`).

Conseils :

- Photo carrée ou verticale, produit bien centré, fond clair et uni.
- Moins de 300 Ko par photo pour que le site reste rapide (vous pouvez les compresser sur squoosh.app).
- Nom de fichier simple, sans espace ni accent : `iphone-16-pro-max.jpg`.

Puis dans `js/produits.js`, ajoutez la ligne suivante dans le produit concerné :

```js
image: "images/produits/iphone-16-pro-max.jpg",
```
